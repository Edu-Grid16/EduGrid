Add a lab PC in 3 steps

  1. Download the EduGrid node agent

    One small Python program. It runs quietly in the background and only uses the PC when nobody is at it.

    Download node agent

  2. Run it once on each lab PC

    Open a terminal as administrator in the folder you downloaded to and run:

    python edugrid-node-agent.py

  3. Link it to your school

    Scan the QR code with a phone signed in as the IT admin, or type the pairing code when the agent asks for it. The PC appears in Infrastructure Fleet within a minute.

    Windows 10/11 or Ubuntu 22.04+Python 3.10+Wired or Wi-Fi internetGraphics card optional (CPU tier)
